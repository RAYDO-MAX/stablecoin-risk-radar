# Stablecoin Risk Radar v1

Public Russian/English research dashboard with a ten-asset initial USD universe. Owner-only GitHub login, private research and citation-based RAG, review queue and configurable freshness profiles.

GitHub Pages hosts React/TypeScript/Vite. Supabase owns PostgreSQL, private documents, Auth and Edge Functions. Upstash Workflow/QStash orchestrates research and schedules; Vector BGE-M3 retrieves evidence. OpenRouter uses deepseek/deepseek-v4.1-flash, only coreweave/fp8 then together. Jev verifies narrow evidence judgments. Tavily extracts documents; heavy PDF/OCR never runs in edge code.

Weights: backing 25, redemption 20, technology 20, governance/counterparties 15, market/peg 10, transparency 10. Unknown mandatory dimensions, conflicting material evidence and confirmed critical events suppress the aggregate. Audit types remain distinct. Evidence quotes, document hashes, reporting periods, model outputs and methodology versions are retained. 100 is rubric fulfillment, not safety probability.

Profiles: economy market 24h/documents 7d/search 7d; balanced 1h/24h/7d; intensive 15m/6h/24h. New assets, methodology changes, conflicts and absolute score deltas >=5 require owner review. Suspected critical events show an immediate review flag; previous published versions remain available on failures.

Private keys never reach public clients. Zero budget disables paid inference. Existing financial files, Supabase projects and BrainBox index are not reused or modified. Free-only provisioning; infrastructure blocks are reported explicitly. Public initial assets have null scores until evaluated, not sample risk numbers.
